# Arnel Gonzales — Portfolio Website

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser. For a local server, run:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Before publishing — important personalisation checklist
1. Replace `YOUR_EMAIL@example.com` in `index.html` with the email address you want recruiters to use.
2. Add your GitHub profile URL and a downloadable résumé if you want those links in the header or contact section.
3. Add approved screenshots or short video clips for Backyard Baseball and your other projects. Use only media you own or have permission to publish.
4. Confirm that all project role descriptions accurately reflect your contribution and any confidentiality restrictions.
5. Update the "Soon", "Grim Days", and "Terebinth" links to their individual project pages if you have them.
6. Confirm whether you want to publicly describe the instant replay feature as unreleased/development-only.

## Hosting
This is a static site and can be hosted free on GitHub Pages, Netlify, or Vercel. No backend is required. The simplest option for a developer portfolio is GitHub Pages.

## Files
- `index.html` — content and structure
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year
